Data tables#

The data tables in multipiegen/data are the source of all generated data. They are curated by hand; some of them are first created by a script in others/creation (it writes next to itself, and the result is copied into multipiegen/data). “origin” is “MultiPie Ver.2.4.0” for the tables taken from MultiPie Ver.2.4.0 (some of them modified), and “new” otherwise. The tables taken from MultiPie Ver.2.4.0 were copied once and have been maintained here since then. The generation never reads the data of MultiPie Ver.2; it uses only its general functions and utilities.

Data that can be derived from these tables are computed in multipiegen instead of being stored:

Orbital and basis definitions: atomic orbitals, spin, LM/JM/LMs/Lgs basis, bra-ket blocks, LaTeX names, Wannier90 aliases, cubic/hexagonal orbitals (internal basis of multipolar harmonics), harmonics keys, max ranks and rank names.

regular atomic spin basis order.

list (4)

regular atomic LM basis order (M: descending).

atomic_jm_basis

list (4)

regular atomic JM basis order (J: ascending, M: descending).

atomic_lms_basis

list (4)

regular atomic spinful basis order.

atomic_lgs_basis

list (4)

regular atomic spinful basis order of the orbitals (Lgs)

atomic_rank_block

list (10)

bra-ket rank block, (L1,L2) for matrix element of atomic SAMB (uppper triangular block only).

atomic_latex_name

dict (18)

convert to regular atomic latex name.

wannier90_orbital

dict (9)

alias for Wannier90: wannier90 -> regular atomic orbital.

cubic_orbital_basis

cubic basis order (multipolar PG harmonics internal basis).

hexagonal_orbital_basis

list (4)

hexagonal basis order (multipolar PG harmonics internal basis).

cubic_basis

list (4)

spinful basis order of cubic_orbital_basis

hexagonal_basis

list (4)

spinful basis order of hexagonal_orbital_basis

orbital_latex_name

dict (41)

convert to latex name up to for internal basis of multipolar PG harmonics and response tensor (add prefix Q/G/T/M).

int

dict (14)

rank name.

data_group_mpg.py#

Group information of the magnetic point groups.

variable

type (size)

description

mpg_info

dict (157)

{ MPG_id: field }

 
Group information for all magnetic point groups.

- mpg_info.
    { MPG_id: field }
    MPG_id: MPG:{PG}.{no}.{ID} (PG:1-37, ID:1-155).
- mpg_tag, mpg_id, mpg_id_set: derived from mpg_info in multipiegen.util.util_group_data.

- field.
    - tag: MPG_id (PG.no.ID).
    - international: international short symbol in LaTeX.
    - schoenflies: Schoenflies symbol in LaTeX.
    - crystal: triclinic, monoclinic, orthorhombic, tetragonal, trigonal, hexagonal, cubic.
    - setting: setting.
    - PG: associated PG, unique.
    - SG: associated SG, MPG -> MSG -> SG.
    - MPG: = id.
    - MSG: associated MSG, 1st MSG in the same MPGs.
    - lattice: "0".
    - hexagonal_g: trigonal or hexagonal ?
    - type: type I, II, III.
    - SO: symmetry operations.

data_root_cluster.py#

Oh and D6h clusters with the representative site and vector.

Created by others/creation/create_root_cluster.py.

variable

type (size)

description

oh_cluster_cart_site0

str

representative site in cartesian coordinate (normalized when necessary), radius of scaled one is given by 1/scale. d6h with principal axis [111] is equivanlent to oh.

d6h_cluster_cart_site0

str

representative site of D6h cluster. (same as oh for principal axis [111])

oh_cluster_cart_vector0

str

representative vector in cartesian coordinate (normalized when necessary). it should not be parallel nor perpendicular to site0 vector. d6h with principal axis [111] is equivanlent to oh.

d6h_cluster_cart_vector0

str

representative vector of D6h cluster. (same as oh for principal axis [111])

cluster_scale

int

scale factor for space group purpose. site0 is scaled as site0/scale.

oh_cluster_cart

str

positions of oh0 cluster in cartesian coordinate (48 points). principal axis [001]. (same as general Wyckoff points)

d6h_cluster_cart

str

positions of D6h cluster in cartesian coordinate (24 points). principal axis [001]. (same as general Wyckoff points)

 
Definition of root cluseter.

- oh_cluster_cart_site0 (str): representative site of Oh cluster.
- d6h_cluster_cart_site0 (str): representative site of D6h cluster. (same as oh for principal axis [111])
- oh_cluster_cart_vector0 (str): representative vector of Oh cluster.
- d6h_cluster_cart_vector0 (str): representative vector of D6h cluster. (same as oh for principal axis [111])
- cluster_scale (int): scale factor (site -> site/scale).
- oh_cluster_cart (str): sites of Oh cluster (first=[x,y,z]).
- d6h_cluster_cart (str): sites of D6h cluster (first=[x,y,z]).

note:
- general points of Oh (oh0).
    - oh0 : gs @ [x,y,z]

- general points of D6h (d6h0).
    - d6h0 : g0s @ [x,y,z], where g0s in principal axis [111] ([-110],[-1-12])
