Group binary#

Create group.pkl (symmetry operation, character, Wyckoff site/bond for all PG, SG, MPG and MSG).

python -m multipiegen.create_binary.create_group [–serial]

Based on MultiPie Ver.2 (others/tools/create_binary/create_data_group.py, create_data_group_mapping.py, create_data_group_bond.py), which are merged here. Differences from MultiPie Ver.2:

  • the representative site/vector are those of the new root cluster (info.pkl).

  • “mapping” of symmetry operation is the mapping to the Oh/D6h cluster (util_op_mapping), for PG and SG.

  • Wyckoff bond has “symmetry” (bond symmetry).

  • complex PG (“-c”) has all data, copied from the real PG except for the character.

  • all sympy values are stored in a simple form (simplify_value).

character_plus(table, conjugacy, so)[source]#

Polar-axial conversion and symmetric and anti-symmetric products of irreps, from the characters.

Parameters:

  • table (dict) – {irrep: [character of each conjugacy class]} (sympy).

  • conjugacy (list) – [[SO tags of each conjugacy class]].

  • so (dict) – symmetry operation (“tag”, “det”, “product”).

Returns:

{irrep: irrep}, “symmetric_product”: {(irrep1, irrep2): [(n, irrep)]},

”anti_symmetric_product”: {irrep: [(n, irrep)]}}.

Return type:

  • (dict) – {“polar_axial”

Notes

  • polar_axial: the irrep whose characters are det(g) times those of the irrep.

  • symmetric_product: decomposition of irrep1 x irrep2 (for irrep1 = irrep2, the symmetric part with characters (chi(g)^2 + chi(g^2))/2); anti_symmetric_product: the anti-symmetric part, (chi(g)^2 - chi(g^2))/2.

  • n = <chi_irrep, chi> / <chi_irrep, chi_irrep>, so that a real irrep of complex type (e.g. E of C4, a pair of complex 1D irreps) is counted once.
