Vector cluster basis#

Orthonormal vector cluster basis (internal rank s=1) of Oh and D6h clusters (binary: cluster_vector_basis.pkl).

This is an intermediate basis to create the bond cluster basis (util_bond_cluster_basis, cluster_bond_basis.pkl); whether it is used by itself is not decided yet.

Same procedure as the cluster basis (util_cluster_basis), for the vector harmonics. s=0 is the cluster basis itself.

  • Vector harmonics. For a real top harmonics T (top key (l, irrep, mul, comp), u-matrix U) and k = -1, 0, 1, the vector harmonics is sum_m U[m] O_{lm}^{(s=1)}(k) (util_multipolar_harmonics, orbital rank l+k), a 3-vector whose components are in the order of the internal basis [px, py, pz] (data_basis.cubic_orbital_basis[1] and hexagonal_orbital_basis[1]).

  • Type. For a polar internal basis (x=”q”), it is polar (X=”Q”) if s+k is even and axial (X=”G”) if s+k is odd; for an axial internal basis (x=”g”), Q and G are interchanged. A polar one has the irrep and component of T (coefficient 1); an axial one has the irrep, component and coefficient c of data_harmonics_mapping, G(key) = c T.

  • Cluster vector. The values at the cluster points (N,3) (see util_cluster_basis.create_cluster).

  • Orthonormalization. Within each (irrep, component), Gram-Schmidt in the order of rank l, then k = -1, 0, 1, then multiplicity; linearly dependent ones are dropped. The result is 3N = 144 (Oh) or 72 (D6h) vectors for each x. The linear dependence is first found numerically, then the kept vectors are orthonormalized exactly.

  • cluster_vector_basis (dict):

    { "Oh/D6h": {
    "site0": [x0,y0,z0] (sympy),
    "cluster": cluster points, ndarray (N,3) (sympy),
    "internal_basis": ["px","py","pz"],
    "basis": { PGMultipoleType: ndarray (dim,N,3) (sympy) },  # orthonormal, sum_{i,a} v_{ia}^2 = 1 per component.
    "dropped": [ PGMultipoleType ],  # vector harmonics linearly dependent on lower ones (whole multiplets).
} }

PGMultipoleType = (X, l, Gamma, n, p, s, k, x) as the vector SAMB of MultiPie Ver.2: type Q/G, rank, irrep,
    multiplicity (-1: unique), add_multiplicity p = -1 (multiplets are distinguished by k), s = 1, k = -1, 0, 1,
    internal type x = q/g. All components of a multiplet are in the value (rows, in the order of components).
