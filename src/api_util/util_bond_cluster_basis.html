Bond cluster basis#

Orthonormal bond cluster basis of Oh and D6h clusters (binary: cluster_bond_basis.pkl).

  • Bond vectors. b_i is the general point i of the Oh or D6h cluster with x,y,z replaced by vector0 (unit vector, info[“root_cluster”][“oh/d6h_vector0_cart”]).

  • Bond cluster vectors. For each vector cluster basis v_key (util_cluster_vector_basis, (N,3)), the N-component vector f_key(i) = v_key(i) . b_i, with the same key. They are 3N vectors in the N-dimensional space.

  • Orthonormalization. Within each (irrep, component), Gram-Schmidt in the order of rank, then k = -1, 0, 1, then multiplicity; linearly dependent ones (including vanishing ones) are dropped. The result is N = 48 (Oh) or 24 (D6h) vectors for each internal basis type x = q, g. The linear dependence is first found numerically, then the kept vectors are orthonormalized exactly.

  • Symmetry. f_key transforms as a scalar function on the cluster, (g f)(i) = s f(j) with R_g^{-1} p_i = p_j, s = 1 (x = q) or det R_g (x = g), with the representation matrices of its irrep.

  • Key. As the anti-symmetric bond cluster SAMB (bond_a) of MultiPie Ver.2, a kept multiplet is a scalar function on the bonds keyed by PGMultipoleType(X, l, Gamma, n, p, s=0, k=0, x), with all components in the value. (X, l, Gamma, n) are those of the vector cluster basis. p (add_multiplicity) numbers the multiplets with the same (X, l, Gamma, n) [components] in the Gram-Schmidt order (k = -1, 0, 1) as 1, 2, …, and is -1 if there is only one. x is the internal type of the vector cluster basis (MultiPie Ver.2 has x = q only).

  • cluster_bond_basis (dict):

    { "Oh/D6h": {
    "site0": [x0,y0,z0] (sympy),
    "vector0": [X0,Y0,Z0] (sympy),
    "cluster": cluster points, ndarray (N,3) (sympy),
    "bond": bond vectors b_i, ndarray (N,3) (sympy),
    "basis": { PGMultipoleType: ndarray (dim, N) (sympy) },  # orthonormal, rows = components.
    "source": { PGMultipoleType: PGMultipoleType },  # multiplet of the vector cluster basis (s=1).
    "dropped": [ PGMultipoleType ],  # multiplets of the vector cluster basis dropped.
} }

PGMultipoleType = (X, l, Gamma, n, p, s, k, x): type Q/G, rank, irrep, multiplicity (-1: unique),
    add_multiplicity (-1: unique), s = 0, k = 0, internal type of the vector cluster basis q/g.
The vector cluster basis (cluster_vector_basis.pkl) is an intermediate basis to create this one.
