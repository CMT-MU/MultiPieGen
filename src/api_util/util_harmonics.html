Harmonics#

Harmonics of all point groups: cartesian expression (symmetry) and u-matrix for each multipole key.

The binary data keyed by PGMultipoleType (multipolar_harmonics.pkl, atomic_multipole_group.pkl, cluster_samb.pkl, the cluster bases) do not hold the expression of the harmonics; look it up here by the key.

  • Harmonics. Every harmonics (X, l, Gamma, n) of a point group is c times a top harmonics T of Oh or D6h (data_harmonics_mapping); its expression is c T (util_top_harmonics.top_harmonics_symmetry) and its u-matrix is c U_T (top_harmonics_u_matrix, rows m = l, l-1, …, -l, columns the components).

  • Key. PGMultipoleType(X, l, Gamma, n, -1, 0, 0, “q”) with X = Q or G. Lookups (harmonics_expression, harmonics_u_matrix) accept any PGMultipoleType (or tuple) and use its (X, l, Gamma, n) only, so the keys of the other binaries can be used as they are; X = T and M (atomic multipoles) use the harmonics of Q and G. n is the multiplicity of the harmonics (1-based, -1 if unique).

  • Order. Gamma (character table), l, X (Q, G), n.

  • Range. 47 point groups, rank l <= 11.

  • harmonics (dict):

    { PG_id: { PGMultipoleType: (expression, u_matrix) } }
    expression: ndarray (dim) (sympy), cartesian expression (polynomial in x, y, z) of each component.
    u_matrix: ndarray (2l+1, dim) (sympy), <m|component> for m = l, l-1, ..., -l.

harmonics_expression(pg, key)[source]#

Cartesian expression of the harmonics of a multipole key.

Parameters:

  • pg (str) – point group tag or id, e.g. “Oh” or “PG:32”.

  • key (PGMultipoleType or tuple) – multipole key; only (X, l, Gamma, n) is used.

Returns:

  • (ndarray) – (dim) expression (sympy) of each component.

harmonics_u_matrix(pg, key)[source]#

u-matrix of the harmonics of a multipole key.

Parameters:

  • pg (str) – point group tag or id, e.g. “Oh” or “PG:32”.

  • key (PGMultipoleType or tuple) – multipole key; only (X, l, Gamma, n) is used.

Returns:

  • (ndarray) – (2l+1, dim) u-matrix (sympy), <m|component> for m = l, l-1, …, -l.
