Binary data for MultiPie#

Binary data for MultiPie (multipiegen/binary_data), in the layout of MultiPie’s multipie/binary_data.

  • info.pkl: information of all groups (= binary/info.pkl).

  • {PG,SG,MPG,MSG}/{id}.pkl: data of each group, with “:” of the id replaced by “_” (git on Windows cannot check out a file name with “:”), e.g. PG/PG_32.pkl, SG/SG_221.pkl, MPG/MPG_32.1.118.pkl, MSG/MSG_221.92.pkl. Each file has its own header (str() of the loaded data).

The data are taken from the binaries in multipiegen/binary (nothing is recomputed, except the representation matrices of PG by util_representation_matrix), and regrouped by group:

  • PG: info, symmetry_operation, wyckoff, character (group.pkl), representation_matrix, harmonics (harmonics.pkl), multipolar_harmonics (multipolar_harmonics.pkl), atomic_samb (atomic_multipole_group.pkl), and cluster_samb (cluster_samb.pkl, real PG only).

  • SG: info, symmetry_operation, wyckoff (group.pkl), and cluster_samb (cluster_samb.pkl).

  • MPG: info, symmetry_operation, wyckoff, active_multipole (group.pkl), and response_tensor (response_tensor.pkl).

  • MSG: info, symmetry_operation, wyckoff (group.pkl).

The SAMB and the multipolar harmonics hold no expression of the harmonics: look it up by (X, l, Gamma, n) of the key in “harmonics” of the PG file (T -> Q, M -> G); for SG and MPG, the PG file is that of info.PG.

group_header(tp)[source]#

Header of a group file.

Parameters:

tp (str) – “PG”, “SG”, “MPG” or “MSG”.

Returns:

  • (str) – header.

group_file(gid)[source]#

File name of a group in binary_data.

Parameters:

gid (str) – group id, e.g. “PG:32”.

Returns:

  • (str) – file name, e.g. “PG/PG_32”.

Note

  • “:” of the id is replaced by “_”, as a file name with “:” cannot be checked out by git on Windows.

create_group_data(gid)[source]#

Data of a group file.

Parameters:

gid (str) – group id, e.g. “PG:32”.

Returns:

  • (BinaryManager) – group data with its header.

create_info_data()[source]#

Data of info.pkl.

Returns:

  • (BinaryManager) – info with its header.

group_ids()[source]#

Ids of all groups, in the order PG, SG, MPG, MSG.

Returns:

  • (list) – group ids.

load_binary_data(name)[source]#

Load a file of binary_data.

Parameters:

name (str) – “info” or a group id, e.g. “PG:32”.

Returns:

  • (BinaryManager) – data, str() gives the description of the keys.
