Multipolar harmonics#

Multipolar harmonics (internal rank s = 1, 2, 3) of point groups with polar (q) and axial (g) internal basis.

Based on MultiPie Ver.2 (others/tools/create_binary/create_data_multipolar_harmonics.py).

  • Harmonics of a point group. For each harmonics (X, l, Gamma, n) of the point group (data_harmonics_mapping, X(key) = c T with the top harmonics T), its cartesian expression is c T and its u-matrix is U = c U_T (m, dim).

  • Internal coefficient. For s = 1, 2, 3 and k = -s..s, internal_coefficient = U^T O_l^{(s)}(k) (dim, 2s+1): the coefficient (polynomial in x, y, z, each element factorized by sympy.factor) of each internal basis function, where O_l^{(s)}(k) is the multipolar spherical harmonics (util_multipolar_harmonics, orbital rank l+k) whose internal components are in the order of the internal basis: the orbitals of data_basis.cubic_orbital_basis[s] (cubic groups, top Oh) or hexagonal_orbital_basis[s] (trigonal and hexagonal groups, top D6h).

  • Internal type. x = “q” (polar internal basis) if (X = Q and s+k even) or (X = G and s+k odd), otherwise “g”.

  • Multipole expression. multipole_expression = internal_coefficient @ (internal symbols) (dim), where the internal symbols are those of info[“harmonics”][“internal_basis”] ((s, x) -> [Q or G + orbital_latex_name of each orbital]).

  • Key. PGMultipoleType(X, l, Gamma, n, p, s, k, x): n is the multiplicity of the harmonics (X, l, Gamma, n), which fixes its xyz polynomial (not renumbered, unlike MultiPie Ver.2); p numbers those with the same (x, l, X, Gamma, n, k) as 1, 2, … (-1 if unique). Vanishing ones (w3j = 0) are excluded.

  • Order. x (q, g), s, Gamma (character table), l, X (Q, G), k, n, p.

  • multipolar_harmonics (dict):

    { PG_id: { PGMultipoleType: (internal_coefficient, multipole_expression) } }
    internal_coefficient: ndarray (dim, 2s+1) (sympy), coefficient (polynomial in x, y, z) of each internal basis
        function, for each component.
    multipole_expression: ndarray (dim) (sympy), multipole expression with the internal symbols.
    The expression of the harmonics (X, l, Gamma, n) itself is in harmonics.pkl (util_harmonics).
