MultiPie Ver.2 からの変更点（多極子のデータ）#

多極子のキーを使うデータについて、MultiPieGen が MultiPie Ver.2 と違うことをしている点（規則、アルゴリズム、 その結果の違い）をまとめたものです。MultiPieGen のアルゴリズム そのものは 多極子データの生成 にあります。下の数字は 2026-11-11 に MultiPie Ver.2 と 比べた結果です（develop 369c8bf の時点）。英語版 もあります。

  • E2g の符号の変更はトップの調和関数の変更です。D6h 系の部分群（六方・三方晶系 16 群の rank 4 の E の多重項）と、 調和関数から作るすべてのデータに引き継がれます。

  • これまで比べた範囲（multipolar harmonics、atomic multipole group）では、調和関数の多重度 n は MultiPie Ver.2 の 振り直した n と結果的に一致していました。規則の違いが効くのは、cluster SAMB の bond_a です。

2. 点群の調和関数#

  • Oh と D6h について一度だけ定義し（data_top_harmonics、util_top_harmonics）、data_harmonics_mapping で 47 点群に対応させます （トップの調和関数の c = ±1 倍）。MultiPie Ver.2 は各点群の調和関数を harmonics.pkl に持っています。

  • 結果：キー (X, l, Gamma, n) は 47 群すべてで同じです（rank ≤ 11）。32 多重項で符号が逆で、すべて E2g の符号の 変更（1 節）によるものです。

4. cluster 基底（新規）#

cluster_scalar_basis.pkl、cluster_vector_basis.pkl、cluster_bond_basis.pkl に当たるものは MultiPie Ver.2 には ありません。いちばん近いのは harmonics_root_cluster.pkl です。

項目

MultiPie Ver.2 harmonics_root_cluster

MultiPieGen の cluster 基底

クラスター

Oh と D6h に共通の 64 点の root cluster

Oh（48 点）と D6h（24 点）を別々に持つ

代表点

MultiPie Ver.2 の点

site0 = (1, 5, 6)、vector0 = (6, 1, 5) の単位ベクトル

中身

各点群の rank 11 までの調和関数の値（直交化していない、一次従属なものも含む）

トップの群の (既約表現, 成分) ごとに低いランクから Gram–Schmidt し、一次従属なものを除いた正規直交基底（正則表現）

内部の種類

x = q

x = q と x = g（vector と bond の基底）

  • キーの形式は、MultiPie Ver.2 の site SAMB（scalar）、vector SAMB（vector）、bond_a（bond）に合わせています。

  • bond の基底は、ベクトル基底とボンドベクトルの内積を取り、ランク、k、多重度の順に Gram–Schmidt して作ります。 MultiPie Ver.2 は反対称ボンドの関数ごとに、最初に重なる vector SAMB のキーを付けますが、その規則は使いません。

項目

MultiPieGen（cluster_samb.pkl）

元にするもの

monopole の順に直交化し、最初に重なる vector SAMB のキーを付ける。p は Wyckoff ごとに振り直す

cluster_bond_basis（x = q）を制限し、[Gamma, l, k, Q/G, n, p] の順に Gram–Schmidt。トップの群のキー（p も）を引き継ぐ

vector SAMB

作る

作らない

ボンドの種類

"bond_s" と "bond_a" を別々に持つ

"bond" = bond_s（Q）+ i bond_a（Q → T、G → M に付け替え）

群

実の点群と空間群

実の点群と空間群（複素の点群は含まない）

  • 結果：すべての Wyckoff のサイトとボンドで、既約表現ごとに張る空間は MultiPie Ver.2 と同じです（サイト 1889、 ボンド 6663）。site と bond_s はキーも同じです。

  • bond_a は、6663 個のボンド Wyckoff のうち 5990 個でキーが違います（T/M に付け替える前のキー、つまり X = Q/G で比べたもの）。

    • p だけ違う（4866）：トップのキーの p を引き継ぐため（例：Oh の 3a@1o は、こちらが Q₁(T1u) p = 1、MultiPie Ver.2 は p = −1）。

    • n が違う（93）：同じ (X, l, Gamma) の別の多重度を使う（例：C4 の 4c@1a は、こちらが Q₂(B) n = 1、MultiPie Ver.2 は n = 2）。

    • (X, l, Gamma) が違う（1031、168 群、うち点群 15 群）：同じ空間に別のキーを付ける。こちらのほうが低いランクに なることが多い（例：C4v の 4f@1a は、こちらが G₁(E)、MultiPie Ver.2 は Q₁(E)）。

  • 値は一致しません。一般点の代表点（site0）が違うためです。

8. そのほかのデータ#

  • 表現行列：47 点群の 241 既約表現すべてで同じです。

  • group.pkl の指標のデータにある既約表現の積（polar–axial の対応、対称積、反対称積）：データ表に持たず、指標から 計算します（create_group.character_plus）。MultiPie Ver.2 との違いは 2 つです。

    • 誤りの修正：C4 と S4 の E、C4h の Eg と Eu（複素型の実 2 次元既約表現）で、MultiPie Ver.2 は対称積を 2A + B、 反対称積を B としています。正しくは A + 2B と A です。基底 (x, y) で、x² + y² が A、x² − y² と xy が B で、 x₁y₂ − y₁x₂ は C4 で不変です（E = Ea + Eb で、Ea⊗Ea = Eb⊗Eb = B、Ea⊗Eb = A）。

    • polar–axial の対応の並びを、指標表の順にしました（10 群で並びが違っていました）。

  • MPG の active multipole（group.pkl）：軌道名を対応させれば同じです（157 群のうち 51 群で軌道名が変わっている。 例：Qf1 → Qfs）。

  • 応答テンソル（response_tensor.pkl）：MultiPie Ver.2 の Group.response_tensor_all と、多極子の名前以外は同じです （binary を作ったときに確認したもので、2026-11-11 の比較には含めていません）。
