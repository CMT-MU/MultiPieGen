# Overall information

PDFs of overall information, created by `python -m multipiegen.create_pdf.create_pdf_info` in `multipiegen/pdf/info/`
from `info.pkl` and `group.pkl`.

| PDF | content |
|---|---|
| [PG](../../multipiegen/pdf/info/PG.pdf) | point groups (47): tag, id, Schoenflies and international symbols, setting, crystal system |
| [SG](../../multipiegen/pdf/info/SG.pdf) | space groups (230): tag, id, symbols, setting, crystal system, point group |
| [MPG](../../multipiegen/pdf/info/MPG.pdf) | magnetic point groups (157): tag, international symbol, setting, crystal system, point group, type |
| [MSG](../../multipiegen/pdf/info/MSG.pdf) | magnetic space groups (1651): tag, BNS and OG symbols, crystal system, PG, SG, MPG, type |
| [compatibility relation](../../multipiegen/pdf/info/compatibility_relation.pdf) | compatibility relation of the Oh and D6h subgroups, with the polar (Q) and axial (G) orbitals of each irrep (component), and the list of orbitals with their expressions |
| [active multipole](../../multipiegen/pdf/info/active_multipole.pdf) | multipoles in the response tensor, and the active multipoles (Q, G, T, M) in each magnetic point group |
