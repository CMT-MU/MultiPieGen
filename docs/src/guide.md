# User Guide

A guide to the quantities provided by MultiPieGen and how to use them, in English (en) and Japanese (ja).

- **Definitions** [[en](guide/definitions.md), [ja](guide/definitions_ja.md)]: crystal harmonics, multipolar
  harmonics, atomic orbitals, atomic SAMB, cluster SAMB (site, bond), and response tensors.
- **Multipole key** [[en](guide/multipole_key.md), [ja](guide/multipole_key_ja.md)]: the key `PGMultipoleType` of the
  harmonics and the SAMB, needed to use them.
