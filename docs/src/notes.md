# Notes

Notes on how the multipole data are generated and how they differ from MultiPie Ver.2, each in English (en) and
Japanese (ja).

- **Generation rules** [[en](notes/generation_rules.md), [ja](notes/generation_rules_ja.md)]: algorithms, keys, and
  orbital bases of the harmonics, multipolar harmonics, cluster bases, cluster SAMB, and atomic multipoles.
- **Changes from MultiPie Ver.2** [[en](notes/changes_from_multipie_v2.md), [ja](notes/changes_from_multipie_v2_ja.md)]:
  conventions, algorithms, and the resulting differences in the multipole data.
