# ユーザーガイド

英語版は[こちら](guide.md)です。

MultiPieGen が提供する量とその使い方のガイドです。英語版（en）と日本語版（ja）があります。

- **定義** [[en](guide/definitions.md), [ja](guide/definitions_ja.md)]：点群調和関数、点群多極子調和関数、原子軌道、原子 SAMB、
  クラスター SAMB（サイト、ボンド）、応答テンソル、そして最後に、調和関数と SAMB を使うのに必要な多極子のキー
  （`PGMultipoleType`）とその LaTeX 記号。
