# MultiPie ボンドデータ（data_wyckoff_bond.py）完全性検証 最終レポート

検証日: 2026-11-08

## 結論
ファイルのボンド型は、通常 Wyckoff 位置ごとに「許される型をすべて尽くしている」。厳密な H 共役では 41 の通常 Wyckoff 位置（82 型）が未掲載に見えるが、全てが、掲載済みの型と、位置パラメータの付け替え（符号反転・入れ替え・ずらし）および心化並進で一致する。付け替えで一致しない型は 0 件、余分な型と重複も 0 件。

## 1. 検証方法
- 対象: 277 群（点群 47、空間群 230）、通常 Wyckoff 位置 1922 個、エントリ 6742 個。ファイルは `ast.literal_eval` で読み込み、実行していない。
- 一般位置のエントリから対称操作を復元し、各通常 Wyckoff 位置 W のサイト対称群 H を求めた。
- 許されるベクトル型は、H×{±1} の部分群 K に対する Fix(K)（零でない固定部分空間）を H 共役で類別したもの。ファイルの各エントリを代表位置へ戻して照合した。
- H 共役で未掲載の型は、さらに次の同一視で再判定した（`check4.py`）。位置 c(p) に対し、g c(p) ≡ c(Σp+s)（Σ は符号付き入れ替え行列、s はずらし）となる演算 g を、心化並進込みの全演算から探し、g の回転部分で型を移して、掲載済みの型と一致するかを見る。これは、c(p) のボンド族を p の付け替えで同じ族とみなすことに当たる。

## 2. 結果
| 項目 | 結果 |
|---|---|
| ファイルにあって許される型にないもの（余分） | 0 件 |
| 同じ型の重複 | 0 件 |
| 空間群の通常 Wyckoff の文字・多重度（pyxtal との比較） | 全 230 群で一致 |
| 点群の層と多重度（独立計算） | 一致 |
| ボンド文字の多重度＝心化数×エントリ数 | 不整合 0 件 |

## 4. Th^4 について
一般位置のエントリから復元した Th^4（Fd-3, #203）の演算は、18/24 個で、並進成分の 1/4 と 3/4 が参照データ（pyxtal）と入れ替わっていた。内訳は、演算番号 2, 3, 4, 6, 7, 8, 10, 11, 12 がファイル 3/4・pyxtal 1/4、演算番号 14, 15, 16, 18, 19, 20, 22, 23, 24 がファイル 1/4・pyxtal 3/4。回転部分は全て一致。原因は参照側の原点の違いで、ファイルは ITA / Bilbao に一致している（ご確認済み）。

## 5. 原点選択
原点選択が 2 通りある 24 群（48, 50, 59, 68, 70, 85, 86, 88, 125, 126, 129, 130, 133, 134, 137, 138, 141, 142, 201, 203, 222, 224, 227, 228 番）の全てで、ファイルの演算は spglib データベースの原点選択 2 に含まれ、原点選択 1 には含まれない（`origin_check.py`）。心化ベクトルは原点選択に依存しない。

## 6. 限界・注意
- 参照データは pyxtal と spglib で、ITA そのものではない。原点選択が 2 通りある 24 群では、参照の Wyckoff 代表座標が原点選択 2 でない。完全性の判定にはファイル自身の演算と位置を使っており、影響しない。
- spglib の演算の並びは ITA の番号付けと一致しないため、演算の並びの照合は ITA / Bilbao に対して行っていない（ご確認済みの Th^4 を除く）。
- 同一視の探索範囲は、符号付き入れ替え行列とずらし（分母 1, 2, 3, 4, 6, 8, 12）。この範囲で全件が解決した。
