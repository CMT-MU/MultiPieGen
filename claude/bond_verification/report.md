# MultiPie ボンドデータ（data_wyckoff_bond.py）完全性検証レポート

検証日: 2026-11-07

## 1. 検証方法
対象は 277 群（点群 47、空間群 230）、通常 Wyckoff 位置 1922 個、エントリ 6742 個。ファイルは `ast.literal_eval` で読み込み、実行していない。

各群について、一般位置のエントリから対称操作を復元し、各通常 Wyckoff 位置 W のサイト対称群 H を求めた。許されるベクトル型は、H×{±1} の部分群 K に対する固定部分空間 Fix(K)（零でないもの）を H 共役で類別したものとした。ファイルの各エントリのベクトルを代表位置へ戻して、この類と照合した。

## 2. 結果
| 項目 | 結果 |
|---|---|
| ファイルにあって許される型にないもの（余分） | 0 件 |
| 同じ型の重複 | 0 件 |
| 空間群の通常 Wyckoff 文字・多重度（ITA / pyxtal との比較） | 一致 |
| 点群の層と多重度（独立計算） | 一致 |
| ボンド文字の多重度＝心化数×エントリ数 | 不整合 0 件 |
| 一般位置から復元した操作と ITA の番号付け | Th^4 のみ並びが異なる |
| **H 共役で欠けているボンド型がある通常 Wyckoff 位置** | **41 件**（30 群） |

## 3. 欠け 41 件の内訳
欠けているのは、リストにある型の鏡像相手（例：`[X,X,Z]` に対する `[X,-X,Z]`）である。

- **グループA（33 件）**: 位置パラメータの反転 p→-p、またはずらし p→p+s で、リスト済みの型と同じ族になる。この同一視を認めるなら欠けとは言えない。
- **グループB（8 件）**: この同一視でも埋まらない。判定基準（H 共役＋パラメータ付け替え）の下では、真に欠けているように見える。MultiPie 側の意図との確認が必要。

## 4. 注意点・未実施の確認
- 判定基準は私が設定したもので、MultiPie の定義そのものではない。A/B の区別も、この基準での結果である。
- 同一視はパラメータの符号反転とずらしのみを試した。パラメータ同士の入れ替え等は試していない。
- 参照データは ITA そのものではなく pyxtal データベースと spglib である。
- ファイル全エントリへ `analyze_bond(centering=...)` を適用した一括検証（`index_matches_given` の確認）は未実施。
- グループBの 8 件は手計算での追確認をしていない。
